Every screen and map toggle works from the keyboard: Tab moves, Enter presses, Esc steps back.
Power saving
Draws a frame only when something changed. A still map costs nothing, so the fans stay quiet. The F3 panel says when it is on.
Preload the next season
Off by default on this Mac: it holds a second set of tiles (about 1.2 GB with winter). On once the compressed tiles are in.
Developer tools
Shows Map sandbox in the main menu and the F3 debug panel. Off in the first public release.
